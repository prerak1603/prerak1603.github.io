About

I'm a Computer Science undergraduate at Bennett University, building software at the point where backend engineering meets applied machine learning. Most of my recent work has been on Aegis AI — a multi-tenant network intrusion detection platform I designed, trained, and shipped solo, from the ML ensemble to the live product around it.

I like taking models out of notebooks and putting them behind clean, production-shaped systems: a FastAPI backend with per-customer auth and rate limiting, a LangGraph agent that grounds its reasoning in retrieved context instead of free-deciding, and a Next.js frontend that never lets an API key touch the browser. On the data side, I care about getting the details right — handling class imbalance, calibrating probabilities, and diagnosing production constraints (like a memory ceiling that forced a rethink of how retrieval worked) so a model's headline accuracy actually means something once it's live.

Outside of code, I'm a member of the Dramatics Club at Bennett University, which keeps me comfortable presenting ideas, coordinating with teams, and thinking on my feet — skills that translate directly into how I work on cross-functional projects.

Selected Projects

Aegis AI — Production AI Security Platform
Aug 2025 – ongoing
Live Machine Learning Full-Stack
  • Built and deployed a 4-model ML ensemble (99.88% accuracy, 13 attack classes, 2.8M+ real network flows) feeding a LangGraph agent that grounds severity assessment and recommendations in a RAG knowledge base — turning raw detections into audited, human-readable threat reports.
  • Found and fixed three separate model failures the headline accuracy number was hiding: a misconfigured LightGBM training at 52% (30-trial Optuna tuning → 99.96%), 0% recall on a rare imbalanced attack class (SMOTE + WGAN-GP → 100% recall, macro F1 90.69% → 98.43%), and a 32.7-point confidence-calibration gap (Platt Scaling → 0.6pp).
  • Diagnosed and fixed a hard 512MB memory ceiling crashing the service in production — redesigned RAG retrieval from a Chroma + neural-embeddings store down to TF-IDF to fit the constraint.
  • Owned the full stack solo: a multi-tenant FastAPI backend (per-customer API-key auth, rate limiting, locked-down CORS) on Neon Postgres, a Next.js/React/TypeScript frontend on Vercel with Clerk authentication, and a signature-verified webhook that auto-provisions accounts on signup.
