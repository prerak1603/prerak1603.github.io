Architecture

A 4-model stacking ensemble (Random Forest, XGBoost, LightGBM → a meta-learner) classifies network flows across 13 attack categories, feeding a LangGraph agent that grounds severity assessment and remediation advice in a RAG knowledge base — the model classifies, the agent explains, and the two never get confused for each other. The whole pipeline sits behind a multi-tenant FastAPI backend (per-customer API keys, rate limiting, Postgres on Neon) with a Next.js frontend on Vercel, Clerk-authenticated end to end.

What the headline number was hiding

99.88% accuracy meant nothing on its own. Getting there honestly meant finding and fixing three separate failures: a misconfigured LightGBM training at 52%, 0% recall on Heartbleed — a handful of examples lost in 2.8M flows — and a 32.7-point gap between the model's stated confidence and its actual correctness. Optuna tuning, SMOTE + WGAN-GP synthetic augmentation, and Platt Scaling calibration fixed each in turn.

The memory-ceiling story

RAG retrieval: Chroma + neural embeddings → TF-IDF

The original RAG layer used a Chroma vector store with neural sentence embeddings. On Render's 512MB free-tier limit, that blew the memory ceiling and crashed the service in production.

Heartbleed recall: 0% → 100%

SMOTE alone couldn't rescue a handful of examples in 2.8M flows. A WGAN-GP trained to generate realistic synthetic Heartbleed flows closed the gap completely.

Confidence calibration gap: 32.7pp → 0.6pp

Platt Scaling brought the model's stated confidence in line with its actual correctness — the difference between a trustworthy "CRITICAL, block now" and noise.
