About

I'm a Computer Science undergraduate at Bennett University, building software at the point where backend engineering meets applied machine learning. Most of my recent work has been on Aegis AI — a security platform with a Java/Spring Boot API on one side and a stacking-ensemble intrusion-detection model on the other.

I like taking models out of notebooks and putting them behind clean, production-shaped APIs: layered architectures, validated request/response models, thread-safe data structures, and sensible fallbacks when the ML layer isn't available. On the data side, I care about getting the details right — handling class imbalance, calibrating probabilities, and tuning thresholds so a model's headline accuracy actually means something.

Outside of code, I'm a member of the Dramatics Club at Bennett University, which keeps me comfortable presenting ideas, coordinating with teams, and thinking on my feet — skills that translate directly into how I work on cross-functional projects.

Aegis AI — Network Intrusion Detection
Aug 2025 – ongoing
Public Repo · ★ 4 Machine Learning
  • Built a stacking ensemble (Random Forest + XGBoost + LightGBM → logistic-regression meta-learner) on 125,000+ NSL-KDD network flow records, reaching 96% accuracy with a macro ROC-AUC of 0.98.
  • Resolved a severe 47,000:5 class imbalance using SMOTE with adaptive k-neighbours, then applied Platt scaling and per-class threshold optimisation to minimise false negatives.
  • Automated a 90-trial Optuna hyperparameter search across all three base models, validated with 5-fold stratified cross-validation that re-runs SMOTE inside every fold to avoid data leakage.
  • Extended the pipeline with synthetic attack traffic via WGAN-GP and a HuggingFace DistilBERT pipeline for threat-intelligence text classification.
